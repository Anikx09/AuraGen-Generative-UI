# AuraGen – Self-Healing Generative UI

## About the Project
AuraGen is an AI-powered project that aims to create adaptive and intelligent user interfaces based on user behaviour and interaction patterns.

## Project Objectives
- Understand user interaction patterns.
- Detect user hesitation and interaction difficulties.
- Adapt the user interface to improve user experience.
- Use Generative AI to create a more user-friendly interface.

## Technologies
- React.js
- JavaScript
- HTML
- CSS
- WebSockets
- Generative AI
