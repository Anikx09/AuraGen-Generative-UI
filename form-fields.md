# AuraGen – Planned Loan Application Form Fields

This is the long financial form that AuraGen will later convert into a step-by-step wizard.

## Section 1: Personal Details
- Full name
- Date of birth
- Gender
- Mobile number
- Email address

## Section 2: Address
- Current address
- City
- State
- PIN code

## Section 3: Identity (KYC)
- PAN number
- Aadhaar number

## Section 4: Employment and Income
- Employment type
- Employer name
- Monthly income
- Years of experience

## Section 5: Loan Details
- Loan amount
- Loan purpose
- Repayment period

## Wizard plan
Each section above will become one step in the wizard.
